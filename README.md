# Post Przerywany

Aplikacja na Androida do postu przerywanego: timer z etapami postu, plany (13:11 … 36h), historia z kalendarzem, statystyki i odznaki, woda, waga z trendem, przypomnienia i licznik w pasku powiadomień.

Łączy się z **Dziennikiem FBW** (ten sam klucz podpisu): treningi w kalendarzu, oznaczenie „trening na czczo”, wspólna waga, status postu widoczny w dzienniku.

APK: zakładka **Releases → latest → post-przerywany.apk** (budowany automatycznie po każdym pushu na `main`).
